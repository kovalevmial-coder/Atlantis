# Атлантис — серверная часть

Веб-приложение развивающего центра «Атлантис»: публичный сайт, кабинеты родителя, учителя и директора.
Node.js + Express (MVC), шаблоны EJS, PostgreSQL.

## Запуск на Windows

1. Установить **Node.js 20+** (nodejs.org) и **PostgreSQL 16** (postgresql.org, при установке запомнить пароль пользователя `postgres`).
2. Создать пользователя и базу (в «SQL Shell (psql)» под `postgres`):
   ```sql
   CREATE USER atlantis WITH PASSWORD 'atlantis';
   CREATE DATABASE atlantis OWNER atlantis;
   ```
3. В папке `server`:
   ```
   npm install
   npm run setup      # .env со случайными ключами, таблицы и тестовые данные
   npm run cert       # самоподписанный сертификат для HTTPS (необязательно)
   npm start
   ```
4. Открыть https://localhost:3443 (или http://localhost:3000, если сертификат не создавался).
   Браузер предупредит о самоподписанном сертификате — это нормально для локального запуска.

Для резервных копий в `.env` укажите `PG_BIN=C:\Program Files\PostgreSQL\16\bin`.
Чтобы письма (коды подтверждения, временные пароли) уходили на почту, заполните `SMTP_*`; без этого они печатаются в консоли сервера.

## Тестовые учётные записи

Пароль у всех `Atlantis2026`.

| Роль | Почта |
|---|---|
| Директор (все точки) | director@atlantis.by |
| Учитель | teacher@atlantis.by |
| Родитель (двое детей) | parent@atlantis.by |
| Родитель (справка на проверке) | parent2@atlantis.by |

Дети, родители и второй учитель вымышленные. Контент сайта (направления, цены, отзывы, вопросы) взят из `js/data.js`.
`npm run seed` пересоздаёт базу с теми же тестовыми данными, `npm run db:init` — пустую базу.

## Структура

```
server/
  server.js            точка входа: HTTPS/HTTP, ночные задачи (копия БД, занятия на 8 недель)
  app.js               Express: helmet, сессии в БД, статика, маршруты, ошибки
  config/              настройки из .env, пул PostgreSQL
  db/schema.sql        скрипт генерации БД (28 таблиц)
  models/              конструктор: описание сущностей и универсальный CRUD
  services/            бизнес-логика (авторизация, расписание, журнал, оплаты, рейтинг, отчёты, копии)
  controllers/         обработчики запросов по разделам
  routes/index.js      все маршруты и права ролей
  views/               шаблоны EJS (public, auth, cabinet, staff, admin, partials)
  public/              клиентские скрипты: API, расписание в стиле ИИС БГУИР, журнал, вход
  scripts/             setup, seed, cert
  tests/               модульные тесты (npm test)
```

Стили и картинки берутся из корня репозитория (`css/`, `img/`, `js/`), поэтому статический макет и сервер выглядят одинаково.
Файл `js/data.js` на сервере формируется из базы данных.

## Безопасность

- пароли — bcrypt; телефоны и даты рождения — AES-256-GCM (ключ `ENC_KEY` в `.env`);
- 5 неверных паролей — вход блокируется на 15 минут; ограничение частоты запросов к входу и заявкам;
- сессии в PostgreSQL, cookie `HttpOnly` + `SameSite=Lax` (+ `Secure` по HTTPS), проверка источника изменяющих запросов;
- заголовки безопасности (helmet, CSP, HSTS), параметризованные SQL-запросы, проверка ввода;
- права по ролям на каждом маршруте; учитель видит только свои группы, директор точки — только свою точку;
- справки открываются только родителю ребёнка и сотрудникам; журнал действий `audit_log`.
