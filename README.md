# Сайт «Атлантис» — клиентская часть

Статическая вёрстка без сервера и БД. Открыть: двойной клик по `index.html`.

## Страницы
| Файл | Что внутри |
|---|---|
| index.html | Главная: первый экран, выбор по задаче, направления, почерк до/после, преимущества, педагог, шаги записи, отзывы, FAQ |
| napravleniya.html | Все направления с фильтром и подробным описанием каждого |
| kalligrafiya.html | Курс каллиграфии, результаты, онлайн-тарифы |
| raspisanie.html | Расписание со свободными местами, фильтры, запись из строки |
| ceny.html | Цены 2026/27 и таблица по направлениям |
| pedagog.html | О педагоге, как проходят занятия, отзывы |
| kontakty.html | Контакты, карта (заглушка), реквизиты, политика конфиденциальности |
| vhod.html | Вход (роли: родитель, педагог, администратор) и регистрация родителя |
| kabinet.html | Демо личного кабинета родителя: абонемент, занятия, посещаемость, группы |

## Файлы
- `css/style.css` — единая таблица стилей. Цвета временные, все в `:root`.
- `js/data.js` — все данные (направления, расписание, цены, отзывы). Позже их будет отдавать сервер.
- `js/ui.js` — общее: меню, модальное окно записи, проверка форм, маска телефона, анимации.
- `js/pages.js` — отрисовка страниц из данных.

## Анимации
Появление блоков при прокрутке, счётчики цифр, слайдер «до/после», подъём карточек при наведении, плавное меню и модальное окно, аккордеон FAQ, заполнение прогресса абонемента, «рисование» галочки после заявки. При системной настройке «уменьшить движение» анимации отключаются.

## Заглушки (заменить)
- Все фото — серые блоки с подписью, что должно быть на фото.
- Расписание, дни занятий, возраст «Познайки» и подготовки к школе.
- Телефон, часы работы, ссылка на Telegram.
- Цены тарифов видеокурса «Я сам» и «Группа», цена «Таблицы умножения».
- Английский: 1–8 или 1–9 класс.
- Данные в личном кабинете (демо).
- Текст политики конфиденциальности.
